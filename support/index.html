tmoxie Support

Trouble connecting, restoring Premium, or getting a session to render correctly? We’ll help you narrow it down.

Contact support

For setup help first, use the tutorials or documentation. Email the support inbox when the app still does not behave as expected.

Email tmoxie.support@gmail.com

Before contacting support

Please include:

  • tmoxie version and build from Settings;
  • iPhone model and iOS version;
  • what you expected, what happened, and exact reproduction steps; and
  • a screenshot if it is safe to share.

Never send an SSH password, private key, recovery code, or access token. Diagnostic logs can include hostnames, usernames, session names, paths, and error text. If raw byte recording was enabled, it can include terminal content. Review and redact files before sharing.

Requirements

  • iPhone with iOS 17 or later;
  • a reachable SSH server and username/password login (SSH key authentication is not included in the current version);
  • tmux installed on the host for session, window, pane, and reconnect features. Hosts without tmux can use the basic plain-SSH fallback; and
  • Local Network permission when connecting over LAN or VPN.

Common fixes

Connection fails

Confirm the hostname or IP, port, VPN or Tailscale connectivity, username, password, and that sshd is running. Try the same connection from another SSH client.

Host key changed

Stop and verify the new fingerprint with the host administrator. Delete the saved trusted key only after confirming the server was legitimately rebuilt or rotated.

Sessions are empty

Run tmux list-sessions on the host, return to Hosts, reconnect, and use pull-to-refresh. tmux sessions live on the remote host, not in tmoxie.

App returned from background

iOS may suspend the SSH connection. tmoxie reconnects after the app becomes active; keeping work inside tmux lets remote processes continue while disconnected.

Dictation unavailable

Enable Microphone and Speech Recognition for tmoxie in iOS Settings. Dictation works only when on-device speech recognition is supported.

Attachment missing

Selected photos and files are uploaded to ~/.tmoxie-uploads on the remote host, then their path is inserted into the active pane or composer. Check remote permissions and free disk space. tmoxie does not automatically delete old uploads, so remove them manually when needed.

Web Preview fails

Web Preview supports HTTP services bound to the remote host’s loopback interface. Confirm the service is listening on 127.0.0.1:<port>. HTTPS preview is not supported in the current version.

Purchase not restored

Open Settings > Plan, choose the Premium options, and tap Restore Purchases while signed into the Apple Account that purchased Premium. Apple handles billing and refund requests.

Diagnostics and deletion

Settings > Diagnostics lets you export or clear the local debug log and opt in to a capped raw terminal-byte recording for one launch. Sharing is always an explicit iOS share action.

Delete a host in tmoxie before uninstalling the app to remove its Keychain password through the app. Delete remote uploads separately from ~/.tmoxie-uploads on the host.
