tmoxie Support

Trouble connecting, restoring Premium, or getting a session to render correctly? We’ll help you narrow it down.

Contact support

Email the tmoxie support inbox. Include the app version and build, iOS version, and a short description of what happened.

Email tmoxie.support@gmail.com

Before you email

  1. Confirm the same hostname, port, username, and credentials work from another SSH client.
  2. Check whether the network, VPN, firewall, or server allows SSH from your iPhone.
  3. For tmux sessions, confirm tmux is installed and runs for the same remote user.
  4. Retry after bringing tmoxie to the foreground. If the display is stale, minimize the session and reopen its window.
  5. For a Premium purchase, use Restore Purchases while signed into the Apple Account that bought it.

Sharing diagnostics safely

tmoxie’s diagnostic logs stay on your device unless you explicitly share them. If support asks for a log, use the app’s share action and inspect the file before sending it.

  • Remove hostnames, IP addresses, usernames, remote paths, terminal output, and anything else you consider sensitive.
  • Never send a password, recovery code, private key, or other secret.
  • Describe the approximate time the problem occurred so the relevant entries are easier to find.

Raw terminal byte capture is a separate, opt-in diagnostic feature. Leave it off unless it is needed to reproduce a rendering problem, and treat the resulting file as sensitive terminal data.

Useful details to include

  • tmoxie version and build from Settings → About;
  • iPhone model and iOS version;
  • whether the connection is plain SSH or tmux;
  • the exact error shown, with sensitive server details removed; and
  • steps that reproduce the problem.
