Before you upgrade.

Is Premium a subscription?

No. Premium Lifetime is one optional in-app purchase. It has no recurring payments.

What happens after the seven-day trial?

The trial starts automatically when you first launch the app. It makes no automatic charge. If you do not buy Premium, Free keeps basic SSH, one saved host, and one selected tmux session, window, and pane target.

Your other saved host records and remote tmux work remain. Access to additional targets and Premium tools requires the upgrade.

How do I buy or restore Premium?

Download tmoxie, open Settings, then open Premium and choose Unlock Premium. Apple shows the regional price before you confirm the purchase.

If you already bought Premium, choose Restore Purchases in the same Premium screen. Use the same Apple Account that made the purchase.

Does Premium include a server or AI service?

You supply the reachable SSH host and the software running there. tmux is required for tmux workspaces. Herdr integration requires a supported Herdr TUI installation. Hosting and any AI service usage are separate.

Supported Herdr releases are stable 0.9.5 with protocol 22, and stable 0.8.x with protocol 19 or 20. The newer Herdr desktop app is a separate product. See Herdr compatibility.

What does Web Preview need?

A running HTTP server on your remote machine's loopback interface, plus permission for SSH port forwarding. HTTPS preview is not supported. Follow the Web Preview setup.

Do agent alerts work in the background?

Premium provides local alerts, haptics, and Live Activity status while tmoxie is active, subject to permissions and the connection. iOS can suspend SSH in the background. tmoxie does not provide always-on monitoring or server push notifications.

The in-app Inbox is included in Free. Read about agent notifications and hooks.
